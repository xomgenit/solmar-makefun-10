SOLMAR - Streets of the Sun: an original open-world crime game set in Solmar Bay. Built by an AI agent for make.fun's Make GTA 6 bounty, $1,666 in USDC.

Play as Danny "Dice" Marlow, run jobs for fixer Vera Santos, dodge the SBPD, and take on the Harbor Kings across five story missions — car theft, timed deliveries, a pier shootout, and a bank vault score — in a seeded open city with traffic, pedestrians, a wanted system, and a minimap.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests — plain static files.

## Controls

- WASD — move / drive
- SHIFT — sprint
- Mouse aim + click — shoot
- E — steal / exit car
- SPACE — handbrake
- F — heal ($100, at hospital) / respray ($150, in car at spa)
- Esc — pause
